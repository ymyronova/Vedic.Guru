# 🪐 Джйотиш-Альманах — веб-сервис

Реальный веб-сервис ведической астрологии: посетитель вводит данные рождения и
получает альманах жизненного пути — натальную карту, силу планет (Вимшопака),
бинду по домам (Сарваштакаварга), дугу даш (Вимшоттари), ключевые йоги и разбор
по каждой планете. Расчёты — на настоящей эфемериде (Swiss Ephemeris, Лахири,
цельнознаковые дома). Текст-интерпретация пишется моделью Claude по уже
посчитанным числам.

> Символический интерпретативный материал — не предсказание.

---

## Как это устроено

```
Браузер (форма: имя / дата / время / место)
        │  POST /api/rectify         → лагна + её описание (шаг 1)
        │  POST /api/rectify_events  → подбор лагны/времени по событиям (шаг 1.2/1.3)
        │  POST /api/almanac         → полный альманах как HTML (шаг 2)
        │  POST /api/synastry        → совместимость двух карт как HTML (шаг 4)
        ▼
FastAPI (backend/)
  ├─ jyotish.py   — вся астрономия и математика (эфемерида, варги, Вимшопака, SAV, даши, каракы, йоги)
  ├─ geo.py       — место → координаты (Nominatim) + верный ИСТОРИЧЕСКИЙ часовой пояс (IANA)
  ├─ charts.py    — SVG-диаграммы (карта, столбцы силы, гистограмма бинду, пузырьки поле×игрок)
  ├─ rectify.py   — ректификация по событиям (даша + транзиты): подбор лагны/времени
  ├─ synastry.py  — совместимость: Аштакута (36), сравнение полей/игроков, интерсинастрия
  ├─ interpret.py — вызов Claude API для прозы (с шаблонным фолбэком без ключа)
  └─ render.py    — сборка готового HTML-альманаха
```

### Ректификация по событиям (`rectify.py`)

Если пользователь не узнаёт предложенную лагну (или не знает времени рождения),
он вводит значимые события жизни (дата + тип). Метод: время рождения почти не
меняет положения планет и дугу даш за сутки, но вращает **лагну** — а с ней и то,
какими домами управляют планеты. Поэтому каждый вариант времени оценивается по
тому, насколько даша, работавшая в момент события, управляет домами-сигнификаторами
темы события (брак→7, карьера→10, дети→5…), с бонусом за транзиты Юпитера/Сатурна
по этим домам. Варианты ранжируются; возвращается вероятная лагна, окно времени,
оценка уверенности и **прозрачный разбор по каждому событию**. Это символический
инструмент-подсказка: он сужает и предлагает, финальное слово — за человеком.

**Ключевой принцип:** все числа считает Python (точно, быстро, бесплатно), а
Claude только *описывает* их словами — модель не выдумывает цифры.

Историю часовых поясов система берёт из базы IANA: например, Киев 26.06.1988
автоматически считается как UTC+4 (советское летнее время) — без ручных таблиц.

## Запуск локально

```bash
# 1. (по желанию) ключ для «живых» текстов
cp .env.example .env      # впишите ANTHROPIC_API_KEY, затем: source .env

# 2. запуск одной командой (создаст venv, поставит зависимости, поднимет сервер)
bash run.sh
```

Откройте **http://localhost:8000**.

Без `ANTHROPIC_API_KEY` сервис работает, но разделы-интерпретации отдаются
шаблоном. С ключом — Claude пишет живой текст на русском.

### Вручную (без run.sh)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...        # по желанию
export JYOTISH_MODEL=claude-sonnet-5       # по желанию
cd backend && uvicorn main:app --reload --port 8000
```

```bash
docker compose up      # соберёт и запустит; откройте http://localhost:8000
```

Другие варианты хостинга:

Это обычное ASGI-приложение (FastAPI). Любой из вариантов подойдёт:

- **Render / Railway / Fly.io:** старт-команда
  `uvicorn main:app --host 0.0.0.0 --port $PORT` (рабочая папка `backend`),
  переменные окружения `ANTHROPIC_API_KEY`, `JYOTISH_MODEL`.
- **VPS + systemd/gunicorn:** `gunicorn -k uvicorn.workers.UvicornWorker main:app`.
- **Docker:** установить `requirements.txt`, запустить uvicorn (см. выше).

Держите API-ключ в переменных окружения хостинга — **никогда** не коммитьте `.env`.

## Стоимость и лимиты

- Расчёты (эфемерида) — бесплатны и мгновенны.
- Один альманах = один вызов Claude (~несколько тысяч токенов). Стоимость зависит
  от выбранной модели — см. https://docs.claude.com/en/docs/about-claude/models
- Геокодер Nominatim бесплатен, но ограничивает ~1 запрос/сек и просит честный
  User-Agent (уже задан). Для нагрузки лучше платный геокодер или своя база городов.
