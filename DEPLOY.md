# 🚀 Как выложить сервис в интернет — пошагово (для новичка)

Эта инструкция предполагает, что вы **никогда раньше не публиковали сайты**.
Мы пройдём всё по шагам, объясняя каждый клик. В конце у вас будет ссылка
вида `https://ваш-сервис.onrender.com`, которую можно отправить подруге.

**Что мы сделаем:**
1. Получим ключ Anthropic (чтобы Claude писал тексты).
2. *(по желанию)* Проверим сервис на своём компьютере через Docker.
3. Выложим код на GitHub.
4. Развернём его бесплатно на Render — и получим публичную ссылку.

Займёт ~30–40 минут. Кредитная карта **не нужна**.

---

## Словарик (три слова, которые встретятся)

- **Docker** — способ «упаковать» программу так, чтобы она одинаково запускалась
  где угодно. Мы уже подготовили эту упаковку (файл `Dockerfile`).
- **GitHub** — бесплатное хранилище для кода в интернете. Render берёт код оттуда.
- **Render** — сервис, который берёт ваш код и превращает его в работающий сайт.

---

## Шаг 0. Получите ключ Anthropic API

Ключ — это пароль, по которому ваш сайт обращается к Claude за текстами.

1. Откройте **https://console.anthropic.com** и войдите/зарегистрируйтесь.
2. Пополните баланс: слева **Billing** → добавьте небольшую сумму (например, $5).
   Один альманах стоит доли цента, так что этого надолго хватит.
3. Слева откройте **API Keys** → **Create Key** → назовите (напр. «jyotish») →
   **скопируйте ключ** (он начинается на `sk-ant-...`).
4. **Сохраните ключ в надёжном месте** — Anthropic покажет его только один раз.

> ⚠️ Никогда не публикуйте этот ключ и не вставляйте его в код. Мы вставим его
> позже в защищённое поле на Render.

*(Без ключа сайт тоже работает, но тексты-интерпретации будут шаблонными.
Ключ включает «живые» тексты от Claude.)*

## Шаг 1 (по желанию). Проверьте на своём компьютере

Это не обязательно, но помогает убедиться, что всё работает, до публикации.

1. Установите **Docker Desktop**: https://www.docker.com/products/docker-desktop
   (есть версии для Windows и Mac). Запустите его — он должен показать «running».
2. Распакуйте `jyotish-almanac.zip` в удобную папку.
3. Откройте **Терминал** (Mac) или **PowerShell** (Windows) и перейдите в эту папку:
   ```
   cd путь/к/папке/jyotish-almanac
   ```
   *(Подсказка: наберите `cd `, затем перетащите папку в окно терминала — путь подставится сам.)*
4. *(если есть ключ)* задайте его на время сессии:
   - Mac/Linux: `export ANTHROPIC_API_KEY=sk-ant-...`
   - Windows PowerShell: `$env:ANTHROPIC_API_KEY="sk-ant-..."`
5. Запустите:
   ```
   docker compose up
   ```
   Первый раз он несколько минут собирает образ — это нормально.
6. Откройте в браузере **http://localhost:8000** — сервис работает локально.
7. Чтобы остановить: вернитесь в терминал и нажмите `Ctrl + C`.

Получилось локально? Отлично — теперь то же самое, но в интернете.

## Шаг 2. Выложите код на GitHub

Самый простой способ без командной строки — программа **GitHub Desktop** (с окнами и кнопками).

1. Зарегистрируйтесь на **https://github.com** (бесплатно).
2. Скачайте и установите **GitHub Desktop**: https://desktop.github.com
   Войдите в нём под своим аккаунтом GitHub.
3. В GitHub Desktop: меню **File → New Repository** (Новый репозиторий).
   - **Name:** `jyotish-almanac`
   - **Local path:** выберите папку, *в которую вы распаковали проект*
     (нужно указать так, чтобы внутри лежали `Dockerfile`, папки `backend`, `frontend`).
   - Нажмите **Create Repository**.
   > Если он говорит, что папка не пуста — ничего страшного, продолжайте: он просто
   > возьмёт имеющиеся файлы.
4. Слева вы увидите список файлов проекта (это и есть ваши изменения).
   Внизу слева впишите короткое описание (напр. «first version») и нажмите
   **Commit to main** («сохранить»).
5. Вверху нажмите **Publish repository** («опубликовать»).
   - Снимите галочку **Keep this code private**, если хотите, чтобы Render-Blueprint
     сработал проще (можно оставить приватным — тогда на шаге 3 Render попросит доступ).
   - Нажмите **Publish**.

Готово — код теперь на GitHub.

> ✅ Файл `.env` с ключом мы **не** публикуем (он и так исключён). Ключ добавим на Render.

## Шаг 3. Разверните на Render

1. Откройте **https://render.com** → **Get Started** → войдите **через GitHub**
   (кнопка «GitHub»). Так Render сразу увидит ваши репозитории. Карта не нужна.
2. В дашборде нажмите **New +** (вверху справа) → выберите **Blueprint**.
   *(Blueprint — это наш файл `render.yaml`, он всё настроит автоматически.)*
3. Найдите и выберите репозиторий **jyotish-almanac** → **Connect**.
   - Если Render просит доступ к репозиториям — разрешите (**Configure**/**Install**).
4. Render прочитает `render.yaml` и покажет один web-сервис `jyotish-almanac`.
   Нажмите **Apply** / **Create Services**.

### Добавьте ключ Anthropic (безопасно)

5. Дождитесь, пока сервис создастся, и откройте его. Слева перейдите в
   **Environment** (Переменные окружения).
6. Найдите переменную **ANTHROPIC_API_KEY** → нажмите **Edit** → вставьте свой
   ключ `sk-ant-...` → **Save Changes**.
   - Переменная **JYOTISH_MODEL** уже задана (`claude-sonnet-5`) — трогать не нужно.
7. Render автоматически пересоберёт сервис с ключом (или нажмите **Manual Deploy → Deploy latest commit**).

> Если на шаге 2 вы **не** использовали Blueprint, можно вместо этого:
> **New + → Web Service → выбрать репозиторий →** Render сам определит `Dockerfile`.
> Тогда в разделе **Environment** добавьте переменную `ANTHROPIC_API_KEY` вручную
> (кнопка **Add Environment Variable**).

## Шаг 4. Откройте свой сайт

1. Дождитесь статуса **Live** (зелёный) — первая сборка занимает несколько минут.
   Следить можно во вкладке **Logs**.
2. Вверху страницы сервиса будет ссылка вида
   **`https://jyotish-almanac.onrender.com`**. Нажмите — откроется ваш сервис!
3. Проверьте: введите дату/время/место, получите альманах. Работает — поздравляю 🎉
4. Отправьте эту ссылку подруге. Ей ничего устанавливать не нужно — просто открыть в браузере.

## Важно знать про бесплатный тариф

- **Сайт «засыпает» после 15 минут без посетителей.** Следующий заход **разбудит**
  его, но первая загрузка займёт ~30–60 секунд (потом быстро). Это нормально для
  бесплатного тарифа. Просто предупредите подругу: «если долго грузится в первый
  раз — подожди минуту».
- Бесплатно даётся **750 часов в месяц** — для личного использования более чем достаточно.
- **Хотите, чтобы не засыпал** (мгновенная загрузка всегда)? Позже можно перевести
  сервис на платный тариф Render от **$7/мес** (Settings → Instance Type → Starter).
  Для начала это не нужно.

## Как обновлять сайт потом

Если мы что-то улучшим в коде:
1. Замените файлы в вашей папке проекта на новые.
2. В **GitHub Desktop**: впишите описание изменений → **Commit to main** → **Push origin**.
3. Render **сам заметит** новый код и пересоберёт сайт за пару минут. Больше ничего не нужно.

---

## Если что-то пошло не так

| Симптом | Что проверить |
|---|---|
| Сборка падает (Failed) | Откройте вкладку **Logs** на Render — там красным написана причина. Чаще всего — не все файлы попали на GitHub (проверьте, что `Dockerfile`, `backend/`, `frontend/`, `requirements.txt` есть в репозитории). |
| Сайт открылся, но тексты «шаблонные» | Не задан или неверен `ANTHROPIC_API_KEY`. Проверьте раздел **Environment**, затем **Manual Deploy**. |
| «Место не найдено» при вводе города | Впишите город точнее («Киев, Украина») или раскройте **координаты вручную** и введите широту/долготу. |
| Первая загрузка очень долгая | Это «пробуждение» после простоя (см. выше). Подождите минуту. |
| Ошибка про баланс/quota от Claude | Пополните баланс в **console.anthropic.com → Billing**. |
| Забыли ключ Anthropic | Создайте новый в **console.anthropic.com → API Keys** и обновите переменную на Render. |

---

## Памятка по безопасности

- Ключ `sk-ant-...` — как пароль. Он живёт **только** в разделе Environment на Render,
  никогда в коде и не на GitHub.
- Если ключ куда-то утёк — зайдите в консоль Anthropic и **отзовите** (delete) его,
  создайте новый.
- Файл `.env` для этого и нужен (локально), и он исключён из публикации через `.dockerignore`.
